# Source provenance

DataDecimals extracts the fixed-point rewrite proposed in JuliaMath/Decimals.jl
PR #121 at `f72dcf1273d80b6d7eab3dea0ff941b666386052`, with review fixes from
`8c2582bc89d894d1ef951a1e84c554ee159ada40` and the export decision in
`556b92be703735efe846d7b6afafa69a14be9838`.

This is a new package with a fresh UUID. It does not replace Decimals.jl.
Original MIT copyright notices are retained. Historical benchmark reports
refer to the earlier rewrite, not a newly measured DataDecimals release.
Jacob Quinn used Claude Code and OpenAI Codex for implementation and review.
